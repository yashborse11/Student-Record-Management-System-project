# Student Record Management System (C)

## 📌 Description
A console-based application built in C to manage student records. The system allows adding, updating, deleting, and searching student details. Data is stored in a binary file for efficient retrieval.

## 🛠️ Technologies Used
- C Programming
- File Handling
- Structures
- Modular Programming

## ✨ Features
- Add new student records
- Display all student records
- Update existing records
- Delete records
- Search by student ID
